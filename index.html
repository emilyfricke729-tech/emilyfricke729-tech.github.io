04 / CODE HIGHLIGHT

Multi-Threading in Java

Ausschnitt aus dem SOC Analyst Simulator – asynchroner Thread für zeitkritische Eingaben.

SecuritySimulator.java — SOC Analyst Mode 
// Asynchroner Timer-Thread für Echtzeit-Countdown
Thread timerThread = new Thread(() -> {
    while (true) {
        long elapsed   = (System.currentTimeMillis() - startTime) / 1000;
        long remaining = timeLimitSec - elapsed;

        if (remaining < 0) break;

        System.out.print("\r⏳ Zeit übrig: " + remaining + "s   ");
        try {
            Thread.sleep(500);
        } catch (InterruptedException ignored) {}
    }
});
timerThread.setDaemon(true);  // automatisch beenden wenn Hauptthread endet
timerThread.start();
